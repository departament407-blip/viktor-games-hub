# Viktor Games Lab

Личный игровой хаб в виде футуристического компьютерного клуба: вращающаяся карусель игровых станций, раздел «Приложения», движущиеся лазеры, музыка, русский и английский интерфейс. React 18, TypeScript и Vite. Хаб не содержит серверы самих игр.

## Запуск и проверка

```bash
npm ci
npm run dev
npm run build
npm test
```

`npm run start` раздаёт готовый `dist`, порт берётся из `PORT`. Сайт пытается включить музыку при открытии: если браузер разрешает Web Audio autoplay, воспроизведение начинается сразу; иначе — после первого клика/касания или клавиши. Кнопка музыки всегда доступна. При скрытии вкладки воспроизведение приостанавливается; вернувшись, нажмите кнопку снова. Ручная пауза и уход с вкладки отменяют ожидающий автозапуск до следующей загрузки страницы; последующие клики не включают музыку повторно.

Новая игра добавляется отдельным объектом в каталог. `playUrl` указывается только для доступной игры. «Властитель Галактики» пока показан как Windows-прототип без кнопки запуска. Внешние игры открываются по их существующим адресам; доступность комнат и авторизации внутри игр проверяется отдельно.

На компьютере и телефоне станции вращаются по кругу: выбранная игра увеличивается в центре. Доступны стрелки, свайп/перетаскивание, клик по соседнему экрану, точки, клавиши ←/→ и Home/End. Отрисовка рассчитана на произвольное число игр; скрытые станции недоступны фокусу. Подробности открываются кнопкой `i`. Диалог закрывается крестиком, Escape или нажатием вне него; фокус возвращается к кнопке. Громкость, язык и настройка эффектов сохраняются локально. Системное `prefers-reduced-motion` отключает движение.

## Приложения

Book Studio открывается по действующему адресу `https://bookstudio-web-production.up.railway.app/`, который переводит на вход владельца. Доступ не меняется; хаб не хранит учётные данные. Вкладки `#games` и `#applications` поддерживают прямую ссылку и историю браузера. Плеер остаётся одним и тем же при переключении разделов.

## Музыка и ассеты

Два оригинальных инструментальных трека созданы в ElevenLabs Music v2 08.11.2026 по запросу владельца:

- **Neon Afterhours** — футуристическое melodic techno, 90 секунд.
- **Orbital Dreams** — атмосферное космическое techno с ностальгическим настроением Facing Worlds / UT99; оригинальная мелодия, без использования записи или сэмплов оригинального саундтрека, 90 секунд.

Файлы MP3 128 kbps приведены к общей целевой громкости −18 LUFS. Web Audio загружает и декодирует плейлист при разрешённом автозапуске или первом действии пользователя, затем планирует шестисекундные equal-power crossfade по аудиочасам и повторяет список. Ползунок управляет общей громкостью обоих треков, включая переход. Анализатор общего сигнала управляет интенсивностью лазеров. API ElevenLabs и ключи на сайте не нужны; музыка раздаётся как статические файлы.

Клубный интерьер и прозрачная мебель созданы по утверждённому пользователем визуальному макету. Новые обложки созданы 08.11.2026: команда из шести сапёров в баре по персонажам владельца, пиратская обложка «Шакала» (Pirate Tabletop) и светящаяся книга Book Studio. Исходное поле Pirate Tabletop сохранено. Rubik хранится локально; лицензия — `public/assets/fonts/OFL-Rubik.txt`.

## Развёртывание

Действующий Railway-сервис `viktor-games-hub` подключён к GitHub `departament407-blip/viktor-games-hub`, ветка `master`, корневая папка `viktor-games-hub`. Изменения делайте в отдельной ветке и сливайте PR в `master` после проверки. Это запускает автоматический production deployment.

Существующий workflow `.github/workflows/deploy-viktor-games-hub.yml` — дополнительный CLI-вариант с `RAILWAY_TOKEN`; основной сервис уже подключён напрямую к GitHub. Не включайте два независимых деплоя без необходимости. Отдельный Railway-проект для редизайна не нужен.

## Необязательный API каталога

Сохранён контракт `GET /api/games`: массив `Game[]` или `{ "games": [...] }`. При ошибке/HTML-ответе используется локальный каталог. `VITE_API_BASE_URL` позволяет задать внешний API. Формат игры описан в `src/features/games/games-types.ts`; обязательны `slug`, `title`, `description`, `status`. Необязательные изображения из локального каталога дополняют ответ API. По умолчанию сайт полностью статический.
